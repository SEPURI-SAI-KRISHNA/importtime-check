# importtime-check 0.1.0a1

This is the first public alpha of `importtime-check`, a CI gate for detecting
CPython import-time regressions. APIs and report formats are pre-1.0 and may
change in later prereleases; review each release's notes before upgrading.

## What's included

- Parse CPython `-X importtime` output into typed import events.
- Measure installed modules in fresh, isolated interpreter processes and use
  repeated samples with an upper-median observation.
- Record and review versioned JSON baselines, then evaluate absolute and
  percentage allowances with exact arithmetic.
- Use the `importtime-check` command for measurements, baseline management,
  text diagnostics, and deterministic schema-1 JSON check results.
- Opt into pytest with the `pytest` extra and
  `-p importtime_check.pytest_plugin`. The core package has no runtime
  dependencies and does not auto-load the plugin.

## Install and start

Install the alpha explicitly:

```console
python -m pip install --pre importtime-check==0.1.0a1
importtime-check measure --module json
```

See the [README](https://github.com/SEPURI-SAI-KRISHNA/importtime-check/blob/main/README.md)
for baseline, CLI, and pytest examples.

## Compatibility and limits

CPython 3.11 through 3.14 are tested. Metadata allows Python 3.11 or newer,
but later versions are not yet part of the supported matrix. Targets must be
installed in the selected interpreter because measurements use isolated mode.
The measured value is CPython's import-time diagnostic for the target, not
whole-process startup time. Host load, dependency changes, and environment
differences can affect results; a matching baseline identity does not make
timings universally comparable. Baselines are reviewable policy files and
are never refreshed implicitly by checks or pytest.
