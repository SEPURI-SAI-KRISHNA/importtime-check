# Security policy

## Supported versions

`importtime-check` is pre-alpha and has no published release. Security fixes are
currently made on the `main` branch on a best-effort basis. This table will be
replaced with a release support policy before the first stable release.

| Version | Supported |
| --- | --- |
| Unreleased `main` | Best effort |
| Published releases | None yet |

## Reporting a vulnerability

Please use
[GitHub private vulnerability reporting](https://github.com/SEPURI-SAI-KRISHNA/importtime-check/security/advisories/new)
to report a suspected vulnerability. Include affected versions or commits, a
minimal reproduction, impact, and any suggested mitigation.

Do not disclose the vulnerability, credentials, tokens, private repository
details, or exploit code in a public issue or discussion. If private reporting
is unavailable, open a public issue containing no sensitive details and ask the
maintainer to establish a private channel.

The maintainer will acknowledge the report when practical, investigate it, and
coordinate validation, remediation, and disclosure with the reporter. No fixed
response-time guarantee is offered while the project is maintained on a
best-effort basis.
